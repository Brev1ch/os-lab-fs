## Задание (уровни 1, 2, 3 A)

Два процесса заносят очередной элемент в связанный список, который хранится в файле.

## Файлы

| Файл | Назначение |
|---|---|
| `filelist.c` | вся программа (init / add / print / demo) |
| `Makefile` | сборка: `make`, очистка: `make clean` |

## Как устроено

- Файл = заголовок (`head`, `tail`, `count`) + узлы (`pid`, `seq`, `next`). Вместо указателей хранятся **смещения** в файле.
- Системные вызовы: `open`, `close`, `read/pread`, `write/pwrite`, `lseek`, `fcntl` (блокировки записи `F_SETLKW`), `fork`, `wait`.
- Добавление узла: захватить блокировку на весь файл → прочитать заголовок → записать узел в конец файла → обновить `next` у прежнего последнего узла → обновить заголовок → снять блокировку.
- Без блокировки (`nolock`) два процесса читают один и тот же заголовок, пишут узлы в одно и то же место и теряют элементы — это и демонстрирует гонку.

## Сборка и запуск

```bash
make
./filelist demo list.dat 10            # два процесса по 10 элементов, с блокировкой
./filelist demo list.dat 50 nolock     # то же без блокировки: список повреждён
```

Вручную в двух терминалах:

```bash
./filelist init list.dat
./filelist add list.dat 20     # терминал 1
./filelist add list.dat 20     # терминал 2 (запустить сразу после первого)
./filelist print list.dat
```

## Результаты

С блокировкой: `count=20, узлов в файле=20, достижимых=20 → список целый`.
Без блокировки: `count=50, узлов в файле=100, достижимых=50 → список ПОВРЕЖДЁН`.
